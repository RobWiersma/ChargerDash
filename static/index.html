How to use ChargerDash

Getting started

  1. Plug each SkyRC iMAX B6AC v2 into this PC with its USB cable. ChargerDash finds it within a few seconds; nothing to set up.
  2. Close SkyRC ChargeMaster first, so the two programs don't fight over the charger.
  3. Give each charger an ID (below), especially if you have more than one.

Use at your own risk. ChargerDash is an unofficial hobby tool, not made or supported by SkyRC. LiPo packs can catch fire: never leave a charge unattended, and charge on a fireproof surface or in a LiPo bag.

Give each charger an ID

These chargers have no serial number, so two of them look identical over USB. To tell them apart, set each one's Waste time to a different value: on the charger, press Batt Type until USER SET PROGRAM, press Start, scroll with ▲▼ to CHG/DCHG WASTE TIME, press Start, change it, press Start to save.

Use anything except 10 min (the factory default), for example 11, 12, 13. Waste time only matters for NiMH/NiCd cycling, so it doesn't affect lithium charging. The charger's tab then shows ID 11 and it's recognised on any USB port, with or without a pack.

Charging

  • Start… opens the program form: battery type (LiPo, LiIon, LiHV), Balance charge or Storage, and the current (0.5 / 1.0 / 1.5 / 2.0 A or your own). Your last choices are remembered per charger.
  • The cell count is detected from the balance lead. The charger checks it against the main lead itself as the program starts, and the dashboard warns if they disagree while it runs. The button says exactly what will run, e.g. Start 6S LiPo storage at 1.0 A. Plug in both the balance and the main lead. Cells starts at the detected count; set it to what the pack's label says. If the two disagree, Start stays off until you check the pack and the balance plug.
  • It refuses to start if the balance lead is missing or has a gap, a cell is below 3.00 V, or a cell is above that battery type's full charge.
  • LiHV charges to 4.35 V per cell. Only choose it for packs marked HV.
  • Stop ends the running program. Programs started on the charger's own buttons show up here too.

Reading the screen

  • All chargers (with two or more) shows every charger side by side. Click a name or Details for its full tab with charts.
  • Cells: each dot is a cell, the line is the pack average, and the mV figure is how far that cell is from it. The spread is the gap between the highest and lowest cell.
  • Internal resistance is measured from how far each cell's voltage jumps when charge current starts, so it needs the app open when the program starts. It includes the balance plug's contact, so it's best for comparing cells and tracking a pack over time. One cell far above the others usually means a weak cell or a poor balance contact.
  • Warnings appear as a chip in the charger's header (click it for details) and as markers on the cells: imbalance (30 / 100 / 200 mV), a cell drifting from the rest, low or over-discharged cells, cells over full charge, leads that disagree, and a hot charger.
  • Time left is an estimate. It learns from every program that finishes with the app open, so it gets better over time. It can't estimate a program the app didn't see start.
  • Click a charger's name to rename it.

Swapping chargers

  • Unplugged chargers keep their tab and last readings; close the tab with ×.
  • When a charger is plugged in, the app recognises it by its ID, by a program it was already running, or by the pack on it. If it can't tell, it asks Which charger is this? in the header.

Logs, phone and sound

  • Logging saves each program to a CSV file (one reading per second). Logs folder opens them. Names, settings and logs live in Documents\ChargerDash.
  • Phone: click the 📱 address in the header for a QR code, and scan it with a phone on the same Wi-Fi (or type the address). If Windows Firewall asks, allow private networks.
  • Sound plays a chime when a program finishes and a warning tone if it stops with an error. Keep the app open (minimised is fine) while charging.
  • If readings stop while a program is running, or the charger drops off USB, a loud alarm repeats even with Sound off, without a break until you press Silence alarm: the charger may still be charging with nothing watching it, so check its screen. The dashboard reconnects by itself when the charger answers again.

Troubleshooting

  • No charger found: check the USB cable, close ChargeMaster, and try another USB port.
  • Charge stops early with an over-capacity error: the charger's Capacity cut-off (User Set menu) is reached. It's 1500 mAh by default, which a big pack can exceed.
  • Charge stops after an hour: that's the charger's Safety timer (60 min by default).
  • Readings look wrong right after plugging in: give it a few seconds; the first readings are skipped until they're trustworthy.
